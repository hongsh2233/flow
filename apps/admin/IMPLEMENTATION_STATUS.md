### 관리자 페이지 노출 기간 설정 기능
현재 관리자 페이지(`/admin/main`)에서 노출 기간을 설정할 수 있는 UI와 API가 필요합니다.

**필요한 작업:**
1. 관리자 페이지 템플릿에 노출 기간 입력 필드 추가
2. 노출 기간 업데이트 API 엔드포인트 추가 (`/admin/main/update-period`)
3. JavaScript로 노출 기간 설정 기능 구현

**간단한 구현 방법:**
- 각 항목에 "설정" 버튼 추가
- 모달 또는 인라인 폼으로 노출 기간 설정
- API 호출하여 업데이트

**향후 개선 사항:**
- 항상 노출 / 기간 내 노출 선택 옵션
- 날짜 선택 UI 개선
- 현재 노출 상태 표시
