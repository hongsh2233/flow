## 야후 파이낸셜(Yahoo Finance) 분석

### 결론: **대부분 제공되지 않음**

야후 파이낸셜은 주로 미국 및 글로벌 증시 데이터에 특화되어 있으며, 한국 증시에 대한 상세 정보는 매우 제한적입니다.

#### 제공 가능한 정보
- 기본 주가 정보 (종가, 시가, 고가, 저가)
- 거래량
- 시가총액
- 기본적인 등락률

#### 제공 불가능한 정보
- ❌ **상한가/하한가 종목**: 한국 증시 전용 개념으로 제공되지 않음
- ❌ **주도 테마**: 한국 증시 특화 분석 데이터로 제공되지 않음
- ❌ **52주 신고가**: 기본적으로 제공되지 않음 (추가 계산 필요)
- ❌ **기관 순매수/순매도**: 한국 증시 전용 투자자 구분 데이터로 제공되지 않음
- ❌ **외국인 순매수/순매도**: 한국 증시 전용 투자자 구분 데이터로 제공되지 않음

## 한국거래소(KRX) Open API 분석

### 현재 프로젝트에서 사용 중인 API
- **KRX API Base URL**: `https://data-dbg.krx.co.kr/svc/apis`
- 현재 사용 중인 엔드포인트:
  - `/idx/kospi_dd_trd` - 코스피 일별 시세
  - `/idx/krx_dd_trd` - 코스닥 일별 시세

### KRX Open API에서 제공 가능한 정보 (확인 필요)

KRX Open API는 다양한 엔드포인트를 제공하지만, 요청한 데이터 항목들은 다음을 통해 확인 가능합니다:

#### 1. 상한가/하한가 종목
- **가능성**: ⚠️ **확인 필요**
- **추정 엔드포인트**: `/sto/stk_mkt/sto_isu_mkt_by_updn_rate` (상승률/하락률 기준 종목 조회)
- **대안**: 종목별 일별 시세 데이터를 조회하여 등락률이 +30%/-30%인 종목 필터링

#### 2. 주도 테마
- **가능성**: ❌ **제공되지 않음**
- **이유**: 테마 분석은 KRX에서 직접 제공하지 않으며, 종목별 업종/테마 정보는 별도 수집 필요
- **대안**: 네이버 금융, 다음 금융 등의 스크래핑 또는 증권사 API 활용

#### 3. 52주 신고가
- **가능성**: ✅ **가능 (데이터 처리 필요)**
- **방법**: 종목별 일별 시세 데이터를 52주간 수집하여 최고가 추출
- **엔드포인트**: `/sto/stk_mkt/sto_isu_dd_trd` - 개별종목 일별 시세

#### 4. 기관 순매수/순매도
- **가능성**: ✅ **가능**
- **엔드포인트**: 
  - `/sto/stk_mkt/sto_isu_by_invst_org` - 투자자별 매매동향
  - `/sto/stk_mkt/sto_isu_by_ivst_org` - 기관별 매매현황
- **참고**: KRX API 문서에서 정확한 엔드포인트 확인 필요

#### 5. 외국인 순매수/순매도
- **가능성**: ✅ **가능**
- **엔드포인트**: 투자자별 매매동향 API에서 외국인 구분 데이터 추출
- **참고**: 기관 순매수/순매도와 동일한 API에서 제공될 가능성 높음

## 권장 사항

### 1. KRX Open API 활용 (우선 추천)
- **장점**: 공식 데이터, 무료, 신뢰성 높음
- **단점**: API 문서 확인 필요, 일부 데이터는 추가 처리 필요
- **필요 작업**:
  1. KRX Open API 명세서 확인
  2. 필요한 엔드포인트 테스트
  3. 데이터 구조 파악 및 파싱 로직 구현

### 2. 공공데이터포털(data.go.kr) 활용
- **장점**: 정부 공식 데이터, 무료, API 제공
- **단점**: 실시간성 제한, 데이터 구조 복잡
- **확인 필요 API**: 
  - 금융위원회 주식시세정보 서비스 (현재 일부 사용 중)
  - 한국거래소 데이터 서비스

### 3. 웹 스크래핑 (최후 수단)
- **대상 사이트**: 네이버 금융, 다음 금융, 증권사 HTS
- **장점**: 다양한 데이터 제공
- **단점**: 법적 리스크, 사이트 구조 변경에 취약, 안정성 낮음
