### 환율 데이터 수집 최적화

**현재 상태**: 30분마다 (48회/일)  
**최적화**: 1시간마다 (24회/일) - **선택사항**

```bash
# 변경 전
CronTrigger(minute="0,30", ...)  # 00:30, 01:00, 01:30, ...

# 변경 후
CronTrigger(minute="0", ...)     # 00:00, 01:00, 02:00, ... (1시간 간격)
```

**예상 절감**: $15/월  
**트레이드오프**: 환율 데이터 실시간성 감소 (30분 → 1시간)  
**권장**: 비즈니스 영향 판단 후 선택
