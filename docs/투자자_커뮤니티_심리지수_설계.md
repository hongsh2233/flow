# 투자자 커뮤니티 심리지수 (Investor Sentiment Index)

## 개요
주요 국내 투자 커뮤니티의 게시글 제목, 반응, 키워드를 수집하고 Gemini AI로 분석하여 투자자 심리지수(0~100)를 생성한다. CNN Fear & Greed Index의 한국 커뮤니티 버전으로, 기존 스크래핑 인프라(httpx+BS4)와 Gemini AI, APScheduler를 재사용한다.

---

## 아키텍처 개요

```
[커뮤니티 수집] → [DB 저장] → [Gemini 감성분석] → [지수 산출] → [API] → [프론트/BO]
     ↓                                                  ↑
  NaverFinance 시장토론        VIX·거래량 등 기존 데이터 병합
  DCInside 주식갤러리
  NaverStockNews(기존)
```

## 1. 데이터 수집 서비스

### 1-1. 네이버 금융 시장토론 스크래핑
- **새 파일**: `apps/admin/app/services/community_sentiment_service.py`
- **대상 URL**: `https://finance.naver.com/forum/boardlist.naver?id=stock_gen` (시장 전체)
- **수집 항목**: 게시글 제목, 조회수, 공감수, 작성시간
- **패턴**: 기존 `naver_finance_service.py`의 httpx + BS4 + EUC-KR 디코딩 재사용
- **헤더**: `naver_supply_service.py`의 `_BASE_HEADERS` 패턴 (Chrome UA, Sec-* 헤더)
- **페이지**: 최신 3~5페이지 (약 60~100개 게시글)
- **Rate limit**: 요청 간 0.5초 대기

### 1-2. DC인사이드 주식갤러리 스크래핑
- **같은 파일**: `community_sentiment_service.py`
- **대상 URL**: `https://gall.dcinside.com/board/lists/?id=stock_new&page=1`
- **수집 항목**: 게시글 제목, 조회수, 추천수, 작성시간
- **인코딩**: UTF-8 (네이버와 다름)
- **주의**: DC는 anti-bot 헤더가 필요하므로 Referer + Sec-Fetch-* 헤더 포함
- **페이지**: 최신 3페이지 (약 60~90개 게시글)

### 1-3. 기존 NaverStockNews 활용
- 이미 수집 중인 `NaverStockNews` 테이블의 제목/설명을 감성분석에 포함
- 새 수집 없음, 기존 데이터 조회만

        Index("ix_community_date_source", "collected_date", "source"),

### 2-2. `SentimentSnapshot` - 심리지수 스냅샷
```python
class SentimentSnapshot(Base):
    __tablename__ = "sentiment_snapshots"
    id = Column(Integer, primary_key=True, autoincrement=True)
    snapshot_date = Column(String(10), nullable=False, index=True)  # YYYY-MM-DD
    snapshot_time = Column(String(5), nullable=False)               # HH:MM
    # 개별 소스 점수 (0~100, 50=중립)
    naver_forum_score = Column(Integer, nullable=True)
    dcinside_score = Column(Integer, nullable=True)
    news_score = Column(Integer, nullable=True)
    vix_score = Column(Integer, nullable=True)
    # 종합 지수
    composite_score = Column(Integer, nullable=False)  # 0~100
    label = Column(String(20), nullable=False)         # "극도의 공포", "공포", "중립", "탐욕", "극도의 탐욕"
    # Gemini 분석 원문
    ai_analysis = Column(Text, nullable=True)          # Gemini 요약 (키워드, 분위기 등)
    top_keywords = Column(Text, nullable=True)         # JSON: ["키워드1", "키워드2", ...]
    created_at = Column(DateTime, nullable=False)
    __table_args__ = (
        UniqueConstraint("snapshot_date", "snapshot_time", name="uq_sentiment_snapshot"),
    )
```

### 2-3. 데이터 보존 정책

- `SentimentSnapshot`: 90일 보존 (트렌드 차트용)

## 3. Gemini 감성분석

### 새 파일: `apps/admin/app/services/sentiment_gemini_service.py`

### Gemini 프롬프트 설계
```
다음은 한국 투자 커뮤니티에서 수집한 최근 게시글 제목들입니다.

[네이버 금융 시장토론]
{naver_titles - 최대 50개}

[DC인사이드 주식갤러리]
{dc_titles - 최대 50개}

[최근 주요 뉴스 제목]
{news_titles - 최대 20개}

다음 JSON 형식으로 분석해주세요:
{
  "naver_forum_score": (0~100 정수, 0=극도의 공포, 50=중립, 100=극도의 탐욕),
  "dcinside_score": (0~100 정수),
  "news_score": (0~100 정수),
  "overall_mood": "한 문장 요약",
  "top_keywords": ["키워드1", "키워드2", ... 최대 10개],
  "reasoning": "2~3문장 근거"
}

분석 기준:
- 매수/상승/급등/호재 관련 제목이 많으면 탐욕 방향 (>50)
- 매도/하락/폭락/악재/공포 관련 제목이 많으면 공포 방향 (<50)
- 욕설·비관적 어조 vs 축제·환호 분위기 반영
- 조회수·추천수가 높은 글에 가중치
```

## 4. 지수 산출 공식

### 종합 지수 계산
```python
def calculate_composite_score(
    naver_score: int,      # Gemini 분석 (0~100)
    dc_score: int,         # Gemini 분석 (0~100)
    news_score: int,       # Gemini 분석 (0~100)
    vix_value: float,      # 기존 Yahoo VIX (^VIX)
) -> int:
    # VIX → 0~100 역변환 (VIX 높으면 공포)
    # VIX 12이하=100(탐욕), VIX 35이상=0(공포), 선형 보간
    vix_score = max(0, min(100, int(100 - (vix_value - 12) * (100 / 23))))
    
    # 가중 평균
    composite = (
        naver_score * 0.30 +    # 네이버 30%
        dc_score * 0.30 +       # DC 30%
        news_score * 0.25 +     # 뉴스 25%
        vix_score * 0.15        # VIX 15%
    )
    return max(0, min(100, round(composite)))
```

### 가중치 근거
| 소스 | 가중치 | 근거 |
|------|--------|------|
| 네이버 시장토론 | 30% | 국내 최대 투자 커뮤니티, 일반 투자자 대표 |
| DC 주식갤러리 | 30% | 고빈도 실시간 반응, 극단적 감성 포착에 유리 |
| 주요 뉴스 | 25% | 객관적 시장 이슈 반영 |
| VIX (공포지수) | 15% | 글로벌 시장 리스크 보정 |

### 라벨 매핑
| 점수 범위 | 라벨 | 색상 |
|-----------|------|------|
| 0~20 | 극도의 공포 | 🔴 빨강 |
| 21~40 | 공포 | 🟠 주황 |
| 41~60 | 중립 | 🟡 노랑 |
| 61~80 | 탐욕 | 🟢 연초록 |
| 81~100 | 극도의 탐욕 | 🟢 진초록 |

## 5. 스케줄러 설정

### 파일: `apps/admin/app/services/scheduler_service.py`에 추가

```python
class SentimentScheduler:
    """커뮤니티 심리지수 스케줄러 (평일 3회)"""
    
    def __init__(self):
        self.scheduler = None
        self.kst = pytz.timezone('Asia/Seoul')
    
    def start(self):
        self.scheduler = AsyncIOScheduler(timezone=self.kst)
        # 09:00, 13:00, 18:00 (평일만)
        for hour in [9, 13, 18]:
            self.scheduler.add_job(
                _run_sentiment_pipeline,
                trigger=CronTrigger(
                    day_of_week='mon-fri',
                    hour=hour, minute=0,
                    timezone=self.kst
                ),
                id=f'sentiment_{hour}',
                replace_existing=True,
                max_instances=1,
                coalesce=True,
            )
        self.scheduler.start()
    
    def shutdown(self):
        if self.scheduler:
            self.scheduler.shutdown()
            self.scheduler = None

sentiment_scheduler = SentimentScheduler()
```

### 실행 파이프라인
```
09:00/13:00/18:00 (KST, 평일)
  ↓
1. collect_community_posts(db)  → CommunityPost 테이블에 저장
  ↓
2. analyze_sentiment(db)        → Gemini로 감성분석 + 지수 산출
  ↓
3. save_snapshot(db)            → SentimentSnapshot 저장
  ↓
4. cleanup_old_data(db)         → 7일/90일 보존 정책 적용
```

### `apps/admin/app/main.py` lifespan에 등록
```python
from app.services.scheduler_service import sentiment_scheduler
# startup
sentiment_scheduler.start()
# shutdown
sentiment_scheduler.shutdown()
```

## 고려사항 및 리스크

### 스크래핑 안정성
- 네이버/DC의 HTML 구조가 변경될 수 있음 → 파싱 로직에 방어적 코드 필요
- IP 차단 가능성 → Rate limit 준수 (0.5초+), 필요시 프록시 지원 (`NAVER_PROXY_URL` 패턴 재사용)
- DC인사이드는 Cloudflare 보호가 있을 수 있음 → Sec-* 헤더 + Referer 필수

### Gemini API 비용
- 1회 호출당 약 120개 제목 (50+50+20) → 토큰 사용량 적음
- 하루 3회 × 30일 = 약 90회/월 → 비용 미미

### 지수 신뢰성
- 초기에는 점수 변동폭이 클 수 있음 → 이동평균(3일) 보정 고려
- 커뮤니티 특성상 극단적 의견이 많음 → VIX로 글로벌 시장 현실 보정
- 장기적으로 실제 시장 수익률과 상관관계 분석 가능

### 향후 확장
- 추가 소스: 뽐뿌 재테크, 클리앙 투자, 텔레그램 채널
- 종목별 심리지수 (개별 종목 토론방 분석)
- 실시간 모드 (1시간 간격)
- 알림: 심리지수 급변 시 푸시 알림 (기존 FCM 인프라 활용)
