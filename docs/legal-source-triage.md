**문서 목적**: 집단 심리 엔진(또는 유사 파이프라인)의 **수집 채널**에 대해 공개 이용약관·개발자 정책 기준으로 1차 리스크를 정리하고, **1단계에서 허용할 소스**를 제품·엔지니어링 기준으로 확정한다.  
**중요**: 본 문서는 **법률 자문이 아니다**. 계약·상업적 재이용·개인정보·저작권·금융광고 규제 등은 **사내 법무 또는 외부 변호사 검토**가 선행되어야 한다.

## 2. 1단계 허용 소스 (확정)

아래는 **엔지니어링·제품 스코프**를 열기 위한 **내부 기준**이다. 법무 승인 전에는 **Reddit도 프로덕션 전면 적용을 보류**할 수 있다.

1. **허용 — 최우선**  
   - **자사/기존 계약 데이터**: BO·`web_new`에서 이미 적법하게 수집·표시하는 뉴스, 시세, 내부 이벤트 로그 등 (목적·보관기간은 개인정보 처리방침과 정합).  
2. **허용 — 조건부 (Reddit만)**  
   - **Reddit 공식 Data API**로만 수집.  
   - **금지(1단계)**: 비로그인 스크래핑, ToS 우회, 한도 초과, **User Content를 약관상 금지된 방식의 AI 학습 데이터로 축적**하는 행위.  
   - **법무 확인 사항**: 상업적 서비스에의 반영, 사용자에게 보여주는 **어트리뷰션**, 데이터 보관·삭제 프로세스, 감정점수 산출이 “학습”에 해당하는지에 대한 해석.  
3. **1단계 제외 (명시적 비허용)**  
   - X 비공식·로그인 기반 수집, 디시인사이드 자동 수집, 네이버 종목토론(및 유사) **비공식 스크래핑**.  
   - 위 소스는 **별도 라이선스·공식 API·사전 서면 합의** 없이 파이프라인에 포함하지 않는다.
