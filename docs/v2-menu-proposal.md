## 배경

v2에서는 아래 두 가지 구조 변경이 전제됩니다.

1. **FE UI + BO UI 통합** — Next.js 단일 앱에서 일반 사용자 화면과 관리자 화면 모두 제공
2. **Python은 순수 백엔드** — 데이터 수집 스케줄러 + DB 조작 전담. REST API 제거.

사용자 요청 핵심 메뉴: **투자운세 / 뉴스 / 관심종목 / 대가들의 한마디**

## 탭별 세부 콘텐츠 제안

### 1. 투자운세 (`/fortune`)

기존 Gemini 기반 운세 → **날짜 시드 순환 방식**으로 대체 (AI 불필요).

```
[오늘 날짜]
┌─────────────────────────┐
│  내 띠: 용 🐲           │
│  오늘의 투자 기운 ★★★☆☆  │
│  용띠는 오늘 분석보다...  │
│  투자 포인트: 급등주보다... │
└─────────────────────────┘

[별자리 탭 전환]
┌─────────────────────────┐
│  내 별자리: 사자자리 ♌   │
│  ...                    │
└─────────────────────────┘

[MBTI 투자성향]
┌─────────────────────────┐
│  내 MBTI: INTJ → 분석형 N │
│  닮은 대가: 찰리 멍거     │
│  투자 스타일: 장기 전략적  │
└─────────────────────────┘
```

**데이터 소스**: `daily_fortunes` 테이블 (Python 스케줄러가 매일 00:30 KST 24개 생성)  
**회원 필드**: `zodiac_animal`, `zodiac_sign`, `mbti_type`, `jubti_type` (기존 DB 컬럼)

---

### 2. 뉴스 (`/news`)

기존 `/briefing`을 리네임 + 수급 정보 흡수.

```
[탭: 전체 | 뉴스 | 리포트 | 시황]

뉴스 카드 목록
├── 제목 / 출처 / 시간
├── 관련 종목 태그
└── (구독 종목 뉴스 우선 노출)
```

**데이터 소스**: `naver_stock_news`, `target_price_news`, `investment_bank_news`, `market_voices`

---

### 3. 관심종목 (`/watchlist`)

기존 `/stocks`(추천)와 즐겨찾기를 통합.

```
[탭: 관심 | 스크리닝 픽 | 수급]

관심 종목 리스트
├── 현재가 / 등락률
├── 삭제·순서 변경
└── 빈 상태: "종목을 추가해보세요"

스크리닝 픽 (하위 탭)
├── 오늘의 픽: 이치모쿠 / 종배 / 밥그릇 / 돌파
└── 그레이드별 필터
```

**데이터 소스**: `master_quote_likes` (관심), 스크리닝 결과 테이블 (픽)

---

### 4. 대가들의 한마디 (`/masters`)

기존 JuBTI 대가 명언 카드 → 독립 탭으로 승격.

```
┌─────────────────────────┐
│  찰리 멍거               │
│  "합리적인 사람은..."    │
│  [좋아요] [다음 명언]    │
└─────────────────────────┘

[내 MBTI 기반 매칭 대가 강조 표시]
[대가별 필터: 버핏 / 멍거 / 소로스 / 린치]
```

**데이터 소스**: `master_quotes` 테이블

## 기존 페이지 v2 처리 방안

| 기존 경로 | v2 처리 |
|---|---|
| `/` (홈) | 제거 → 투자운세(`/fortune`)가 기본 진입점 |
| `/search` | 상단 검색 아이콘으로 대체 (모달 또는 오버레이) |
| `/briefing` | `/news`로 통합·리네임 |
| `/stocks` | `/watchlist` 내 스크리닝 픽 탭으로 편입 |
| `/settings` | 상단 프로필 아이콘 → 설정 페이지 (탭 아님) |
| `/market` (수급) | `/watchlist` 또는 `/news` 내 탭으로 흡수 |
| `/calendar` | 향후 재검토 (투자 일정 기능이 강화되면 복원) |
| `/board` | v2 사용자 앱에서 제외, BO에서만 관리 |
| `/report` | `/news` 내 리포트 탭으로 흡수 |
| `/stock-chat` | v2 제외 (커뮤니티 기능 방향 결정 후 재검토) |
| `/supply` | `/watchlist` 내 수급 탭으로 흡수 |

## 구현 우선순위

```
Phase 1: 앱 골격
  └─ dev 브랜치 + apps/web/ 디렉토리 세팅
  └─ 4개 탭 라우트 생성 (/fortune, /news, /watchlist, /masters)
  └─ 레이아웃: 바텀 탭 4개 + 상단 검색/프로필 아이콘

Phase 2: 탭 구현 (우선순위 순)
  1. 뉴스 — 기존 /briefing 데이터 그대로 활용 (가장 빠름)
  2. 관심종목 — 기존 즐겨찾기 API + 스크리닝 결과 조회
  3. 대가들의 한마디 — 기존 master_quotes 조회
  4. 투자운세 — 날짜 시드 운세 + MBTI 정적 프로필

Phase 3: Python scheduler 이전
  └─ apps/admin → apps/scheduler (REST 라우터 제거)
```

## 미결 사항

- [ ] 투자운세를 기본 진입점으로 할지, 아니면 뉴스를 기본으로 할지
- [ ] 수급(`/market`) 데이터를 관심종목 탭에 넣을지 뉴스 탭에 넣을지
- [ ] 검색을 모달로 처리할지, 별도 페이지(`/search`)로 유지할지
- [ ] 로그인 필수 여부: 투자운세는 비로그인도 보여줄지 (띠·별자리 선택 후)
